## 2. Positionnement dans l'écosystème iFay

ICP est né au sein de l'écosystème iFay, mais sa valeur s'étend au-delà d'iFay. Ce chapitre clarifie la position architecturale d'ICP dans l'écosystème iFay, ainsi que sa valeur universelle en tant que standard de protocole indépendant.

### Architecture en couches d'iFay et position d'ICP

Le Framework iFay adopte une architecture à cinq couches :

- **Couche Context** (couche supérieure) : Responsable de l'assemblage des messages multimodaux modulaires, de la traduction de Prompt, des API de périphériques locaux, des API de transfert de données et de l'intégration des API distantes
- **Couche Protocol** : Définit l'ensemble des protocoles pour l'interaction d'iFay avec le monde extérieur
- **Couche cœur iFay** : Contient quatre modules de capacités — Credentials, Sense, Action et Thought — pilotés par l'Ego Model
- **Couche Virtual Runtime Environment** : Environnement d'exécution d'iFay, supportant ordinateurs, robots incarnés, conteneurs, terminaux, serveurs/cloud et intégration in-app, géré par le runtime FayGer
- **Global Merit Chain** (couche verticale) : Système de réputation et de valeur traversant l'ensemble du framework

ICP (Interactive Conversation Protocol) se situe dans la couche Protocol, en tant que membre de la suite de protocoles iFay, aux côtés de cinq autres protocoles.

### Définition d'iFay

iFay est un agent IA personnel (Personal AI Agent) attaché à une personne physique. Chaque iFay est lié un-à-un avec une personne physique, comprenant en profondeur les préférences, habitudes, relations sociales et contexte de vie de l'utilisateur.

### Définition de coFay

coFay est un agent IA de rôle public (Public Role AI Agent) qui remplit des fonctions publiques sociales, jouant des rôles définis tels que policier, médecin, enseignant, fonctionnaire ou représentant du service client.

### Valeur indépendante d'ICP

Bien qu'ICP soit né dans l'écosystème iFay, il est conçu comme un protocole de description sémantique indépendant utilisable sans iFay. Tout système nécessitant une description structurée de la sémantique d'interaction homme-machine peut adopter ICP.
