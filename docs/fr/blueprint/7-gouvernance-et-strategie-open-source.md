## 🤝 7. Gouvernance du projet et stratégie open source

ICP est un projet open source dont le succès à long terme dépend de structures de gouvernance transparentes et d'une participation communautaire active.

### Positionnement open source

ICP est publié sous une licence open source, garantissant que toute personne, organisation ou entreprise peut librement utiliser, modifier et distribuer la spécification du protocole et les outils associés.

Valeurs fondamentales open source :

- **Transparence** : Toutes les décisions de conception, discussions et enregistrements de modifications sont publiquement accessibles
- **Collaboration** : Encourager les développeurs du monde entier à participer à l'évolution du protocole
- **Piloté par la communauté** : La direction de développement du protocole est déterminée par les besoins et le consensus de la communauté

### Modèle de gouvernance

Le projet adopte une structure de gouvernance en couches :

- **Core Maintainers** : Détiennent les permissions de merge et les droits de décision architecturale
- **Contributors** : Membres de la communauté soumettant du code, de la documentation ou des traductions via Pull Requests
- **Community Members** : Le groupe plus large participant aux discussions, soumettant des Issues et fournissant des retours

Processus de décision :

1. Les changements majeurs du protocole sont avancés via le processus de proposition RFC
2. Les propositions RFC passent par une période de discussion publique
3. Les Core Maintainers prennent les décisions finales basées sur le consensus communautaire
4. Toutes les décisions et justifications sont documentées publiquement

### Mécanismes de participation communautaire

- **Guide de contribution** : Processus détaillés de contribution pour le code, la documentation et les traductions
- **Canaux de communication** : GitHub Discussions pour les discussions techniques, Issues pour le suivi des problèmes
- **Code de conduite** : Standards de comportement communautaire clairs pour un environnement de collaboration inclusif
- **Contributions de traduction** : Les traductions en 9 langues sont réalisées collaborativement, le chinois étant la version source
