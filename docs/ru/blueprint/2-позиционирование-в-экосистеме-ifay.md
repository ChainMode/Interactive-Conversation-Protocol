## 2. Позиционирование в экосистеме iFay

ICP родился в экосистеме iFay, но его ценность выходит за рамки iFay. Эта глава разъясняет архитектурную позицию ICP в экосистеме iFay, а также его универсальную ценность как независимого стандарта протокола.

### Многоуровневая архитектура iFay и позиция ICP

Фреймворк iFay использует пятиуровневую архитектуру:

- **Уровень Context** (верхний): Отвечает за сборку модульных мультимодальных сообщений, перевод Prompt, локальные API устройств, API передачи данных и интеграцию удалённых API
- **Уровень Protocol**: Определяет набор протоколов для взаимодействия iFay с внешним миром
- **Ядро iFay**: Содержит четыре модуля способностей — Credentials, Sense, Action и Thought — управляемые Ego Model
- **Уровень Virtual Runtime Environment**: Среда выполнения iFay, поддерживающая компьютеры, воплощённых роботов, контейнеры, терминальные устройства, серверы/облако и встраивание в приложения, управляемая средой выполнения FayGer
- **Global Merit Chain** (вертикальный уровень): Система репутации и ценности, пронизывающая весь фреймворк

ICP (Interactive Conversation Protocol) находится на уровне Protocol как член набора протоколов iFay, наряду с пятью другими протоколами.

### Определение iFay

iFay — это персональный ИИ-агент (Personal AI Agent), привязанный к физическому лицу. Каждый iFay связан один-к-одному с физическим лицом, глубоко понимая предпочтения, привычки, социальные связи и жизненный контекст пользователя.

### Определение coFay

coFay — это ИИ-агент публичной роли (Public Role AI Agent), выполняющий социальные публичные функции, такие как полицейский, врач, учитель, государственный служащий или представитель службы поддержки.

### Независимая ценность ICP

Хотя ICP родился в экосистеме iFay, он спроектирован как независимый протокол семантического описания, который можно использовать без iFay. Любая система, которой необходимо структурно описывать семантику взаимодействия человека и машины, может принять ICP.
