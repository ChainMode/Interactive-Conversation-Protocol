# Interactive Conversation Protocol

## 1. Определение проекта

Interactive Conversation Protocol (ICP) — это структурированный протокол для описания директивных значений. Клиенты могут комбинировать директивные значения в распознаваемые человеком модульные мультимодальные сообщения на основе структуры этого протокола.

**Ключевая позиция**: Промежуточная языковая форма для взаимодействия человека и машины, по сути структурированное текстовое представление графа концепций, которое мы называем "Conception Annotation" (Аннотация концепции).
