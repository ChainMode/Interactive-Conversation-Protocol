## 2. Posicionamiento en el Ecosistema iFay

ICP nació dentro del ecosistema iFay, pero su valor se extiende más allá de iFay. Este capítulo aclara la posición arquitectónica de ICP dentro del ecosistema iFay, así como su valor universal como estándar de protocolo independiente.

### Arquitectura por capas de iFay y posición de ICP

El Framework iFay adopta una arquitectura de cinco capas:

- **Capa Context** (capa superior): Responsable del ensamblaje de mensajes multimodales modulares, traducción de Prompt, API de dispositivos locales, API de transferencia de datos e integración de API remotas
- **Capa Protocol**: Define el conjunto de protocolos para la interacción de iFay con el mundo exterior
- **Capa núcleo iFay**: Contiene cuatro módulos de capacidad — Credentials, Sense, Action y Thought — impulsados por el Ego Model
- **Capa Virtual Runtime Environment**: Entorno de ejecución de iFay, soportando computadoras, robots encarnados, contenedores, dispositivos terminales, servidores/nube e integración en aplicaciones, gestionado por el runtime FayGer
- **Global Merit Chain** (capa vertical): Sistema de reputación y valor que abarca todo el framework

ICP (Interactive Conversation Protocol) reside en la capa Protocol, como miembro de la suite de protocolos iFay, junto a otros cinco protocolos.

### Definición de iFay

iFay es un agente de IA personal (Personal AI Agent) vinculado a una persona natural. Cada iFay está enlazado uno a uno con una persona natural, comprendiendo profundamente las preferencias, hábitos, relaciones sociales y contexto de vida del usuario.

### Definición de coFay

coFay es un agente de IA de rol público (Public Role AI Agent) que desempeña funciones públicas sociales, como policía, médico, profesor, funcionario o representante de servicio al cliente.

### Valor independiente de ICP

Aunque ICP nació dentro del ecosistema iFay, está diseñado como un protocolo de descripción semántica independiente que puede usarse sin iFay. Cualquier sistema que necesite describir estructuralmente la semántica de interacción humano-máquina puede adoptar ICP.
