## 🤝 7. Gobernanza del Proyecto y Estrategia Open Source

ICP es un proyecto open source cuyo éxito a largo plazo depende de estructuras de gobernanza transparentes y participación activa de la comunidad.

### Posicionamiento open source

ICP se publica bajo una licencia open source, garantizando que cualquier persona, organización o empresa pueda usar, modificar y distribuir libremente la especificación del protocolo y herramientas relacionadas.

Valores fundamentales open source:

- **Transparencia**: Todas las decisiones de diseño, discusiones y registros de cambios son públicamente accesibles
- **Colaboración**: Alentar a desarrolladores globales a participar en la evolución del protocolo
- **Impulsado por la comunidad**: La dirección de desarrollo del protocolo es determinada por las necesidades y consenso de la comunidad

### Modelo de gobernanza

El proyecto adopta una estructura de gobernanza por capas:

- **Core Maintainers**: Poseen permisos de merge de código y derechos de decisión arquitectónica
- **Contributors**: Miembros de la comunidad que envían código, documentación o traducciones vía Pull Requests
- **Community Members**: El grupo más amplio que participa en discusiones, envía Issues y proporciona retroalimentación

Proceso de decisión:

1. Los cambios importantes del protocolo se avanzan mediante el proceso de propuesta RFC
2. Las propuestas RFC pasan por un período de discusión pública
3. Los Core Maintainers toman decisiones finales basadas en el consenso comunitario
4. Todas las decisiones y justificaciones se documentan públicamente

### Mecanismos de participación comunitaria

- **Guía de contribución**: Procesos detallados de contribución para código, documentación y traducciones
- **Canales de comunicación**: GitHub Discussions para discusiones técnicas, Issues para seguimiento de problemas
- **Código de conducta**: Estándares claros de comportamiento comunitario para un entorno de colaboración inclusivo
- **Contribuciones de traducción**: Las traducciones en 9 idiomas se realizan colaborativamente, siendo el chino la versión fuente
