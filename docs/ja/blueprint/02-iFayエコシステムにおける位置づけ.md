## 2. iFay エコシステムにおける位置づけ

ICP は iFay エコシステムから生まれましたが、その価値は iFay に限定されません。本章では、iFay エコシステムにおける ICP のアーキテクチャ上の位置と、独立したプロトコル標準としての汎用的価値を明らかにします。

### iFay の階層アーキテクチャと ICP の位置

iFay Framework は5層アーキテクチャを採用しています：

- **Context 層**（最上層）：モジュラーマルチモーダルメッセージ（Modular Multimodal Messages）の組み立て、Prompt 翻訳、ローカルデバイス API、データ転送 API、リモート API の接続を担当
- **Protocol 層**：iFay と外部世界とのインタラクションのためのプロトコル集合を定義
- **iFay コア層**：クレデンシャル（Credentials）、感知（Sense）、行動（Action）、思考（Thought）の4つの能力モジュールを含み、基盤はエゴモデル（Ego Model）によって駆動
- **Virtual Runtime Environment 層**：iFay の実行環境。コンピュータ、具現化ロボット、コンテナ、端末デバイス、サーバー/クラウド、アプリ内組み込みなど多様なキャリアをサポートし、FayGer ランタイムによって管理
- **Global Merit Chain**（縦断層）：全体を貫く信用と価値のシステム

ICP（Interactive Conversation Protocol）は Protocol 層に位置し、iFay プロトコルスイートの一員として、他の5つのプロトコルと並列しています：

| プロトコル | 責務 |
|-----------|------|
| Faying Protocol | iFay 間のソーシャルおよびアイデンティティプロトコル |
| **Interactive Conversation Protocol (ICP)** | **人機インタラクティブ会話のセマンティック記述プロトコル** |
| Telepathy Protocol | 意図と心的状態の伝達プロトコル |
| Control Authority Protocol | 権限制御と認可プロトコル |
| Data Tunnel Protocol | データチャネルと転送プロトコル |
| Skill Sharing Protocol | スキル共有と呼び出しプロトコル |

ICP は「インタラクティブ会話」という人機インタラクションシナリオに特化しています——iFay がユーザーと構造化された会話インタラクションを行う必要がある場合、ICP は現在の端末の客観的コンテキストに基づいて、セマンティックコンテンツをユーザーフレンドリーなインタラクティブインターフェースに動的に組み立てる責任を担います。

### iFay の定義

iFay は自然人に紐づく個人 AI エージェント（Personal AI Agent）です。各 iFay は一人の自然人と一対一で結びつき、そのユーザーの好み、習慣、社会的関係、生活コンテキストを深く理解します。iFay の核心的責務は、個人を代表して情報を処理し、インタラクションを管理し、外部世界とのコミュニケーションを調整することです。

iFay は、あなたを本当に理解するデジタルアシスタントと考えることができます——あなたが言ったことを覚えているだけでなく、あなたの表現習慣、意思決定の好み、現在の状況を理解しています。

### coFay の定義

coFay は社会的公共機能を担う AI エージェント（Public Role AI Agent）です。iFay の個人的性質とは異なり、coFay は警察官、医師、教師、公務員、カスタマーサービス担当者など、定義された公共的役割を演じます。

iFay と coFay の核心的な違いは、サービス対象と責任の境界にあります：

- iFay は特定の個人にサービスを提供し、その個人の完全なコンテキストを理解し、個人の利益を代表する
- coFay は公共機能にサービスを提供し、役割仕様と職業ガイドラインに従い、公共の利益を代表する

### ICP の独立した価値

ICP は iFay エコシステムから生まれましたが、iFay に依存せずに使用できる独立したセマンティック記述プロトコルとして設計されています。

人機インタラクションのセマンティクスを構造的に記述する必要があるあらゆるシステムが ICP を採用できます：チャットアプリケーション、音声アシスタント、AR/VR プラットフォーム、企業コラボレーションツール、IoT デバイスコントロールパネル——「人と機械の間でコンテキスト付きの構造化情報を伝達する必要がある」シナリオがある限り、ICP は活躍の場があります。

ICP はしたがって二重のアイデンティティを持ちます：

- iFay エコシステム内では、Protocol 層におけるインタラクティブ会話のセマンティック記述プロトコル
- iFay エコシステム外では、あらゆる人機インタラクションシナリオに適用可能な、コンテキストを含む汎用セマンティック記述プロトコル
