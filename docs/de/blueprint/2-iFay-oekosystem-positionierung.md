## 2. Positionierung im iFay-Ökosystem

ICP wurde im iFay-Ökosystem geboren, aber sein Wert geht über iFay hinaus. Dieses Kapitel erläutert die architektonische Position von ICP im iFay-Ökosystem sowie seinen universellen Wert als unabhängiger Protokollstandard.

### iFays Schichtenarchitektur und ICPs Position

Das iFay Framework verwendet eine Fünf-Schichten-Architektur:

- **Context-Schicht** (oberste Schicht): Zuständig für die Zusammenstellung modularer multimodaler Nachrichten, Prompt-Übersetzung, lokale Geräte-API, Datenübertragungs-API und Remote-API-Integration
- **Protocol-Schicht**: Definiert die Protokollsammlung für iFays Interaktion mit der Außenwelt
- **iFay-Kernschicht**: Enthält vier Fähigkeitsmodule — Credentials, Sense, Action und Thought — angetrieben vom Ego Model
- **Virtual Runtime Environment-Schicht**: iFays Laufzeitumgebung, unterstützt Computer, verkörperte Roboter, Container, Endgeräte, Server/Cloud und In-App-Einbettung, verwaltet durch die FayGer-Laufzeit
- **Global Merit Chain** (vertikale Schicht): Ein die gesamte Architektur durchspannendes Reputations- und Wertsystem

ICP (Interactive Conversation Protocol) befindet sich in der Protocol-Schicht als Mitglied der iFay-Protokollsuite, neben fünf weiteren Protokollen:

| Protokoll | Verantwortung |
|-----------|--------------|
| Faying Protocol | Sozial- und Identitätsprotokoll zwischen iFay-Instanzen |
| **Interactive Conversation Protocol (ICP)** | **Semantisches Beschreibungsprotokoll für Mensch-Maschine-Konversationen** |
| Telepathy Protocol | Protokoll zur Übertragung von Absichten und mentalen Zuständen |
| Control Authority Protocol | Berechtigungskontroll- und Autorisierungsprotokoll |
| Data Tunnel Protocol | Datenkanal- und Übertragungsprotokoll |
| Skill Sharing Protocol | Skill-Sharing- und Aufrufprotokoll |

### Definition von iFay

iFay ist ein persönlicher KI-Agent (Personal AI Agent), der an eine natürliche Person gebunden ist. Jeder iFay ist eins-zu-eins mit einer natürlichen Person verbunden und versteht die Vorlieben, Gewohnheiten, sozialen Beziehungen und den Lebenskontext des Benutzers tiefgehend.

### Definition von coFay

coFay ist ein KI-Agent für öffentliche Rollen (Public Role AI Agent), der soziale öffentliche Funktionen übernimmt. Im Gegensatz zu iFays persönlicher Natur spielt coFay definierte öffentliche Rollen wie Polizist, Arzt, Lehrer, Beamter oder Kundendienstmitarbeiter.

### ICPs unabhängiger Wert

Obwohl ICP im iFay-Ökosystem entstanden ist, wurde es als unabhängiges semantisches Beschreibungsprotokoll konzipiert, das ohne iFay verwendet werden kann. Jedes System, das Mensch-Maschine-Interaktionssemantik strukturiert beschreiben muss, kann ICP übernehmen.
